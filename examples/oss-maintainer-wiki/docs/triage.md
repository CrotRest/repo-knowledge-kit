# Issue Triage Rules

Incoming issues should be classified before implementation begins.

## Required Fields

- Expected behavior
- Actual behavior
- Minimal reproduction
- Environment

## Decisions

Maintainers can accept, close as duplicate, ask for reproduction, or escalate security reports.
